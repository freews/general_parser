##### 5.3.2.10 Access Control Metadata Group - Authority (Object Table)

> **Section ID**: 5.3.2.10 | **Page**: 165-166

Begin Informative Content
A row of the Authority Table is called an authority.  An authority is a specific use of a credential and,
possibly, other authorities.  A class authority is an authority object referenced by multiple individual
authorities and does not use a credential.
End Informative Content
