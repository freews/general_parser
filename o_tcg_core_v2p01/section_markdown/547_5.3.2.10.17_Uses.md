###### 5.3.2.10.17 Uses

> **Section ID**: 5.3.2.10.17 | **Page**: 169-169

This column defines the total number of successful authentications made with this authority, including
both successful session start-up invocations and Authenticate method invocations.  The value of the
Uses column identifies the number of times an authority has been successfully authenticated.
If the value of Uses is equal to or greater than the value of Limit for this authority and the value of the
Limit column is not 0, then this authority SHALL NOT be authenticatable.
This value SHALL NOT be subject to transactional rollbacks.
