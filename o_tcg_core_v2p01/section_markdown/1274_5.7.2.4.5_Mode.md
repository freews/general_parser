### 5.7.2.4.5 Mode

> **Section ID**: 5.7.2.4.5 | **Page**: 277-277

This is a name that MAY be shared by multiple K_AES_256 objects.
For objects in this table that exist at issuance, this column SHALL NOT be modifiable by the host.
This column stores the key associated with this K_AES_256 object.  Non-tweakable cipher modes such
as ECB, CBC, CFB, OFB, GCM, CCM, and CTR SHALL use the 32-byte option for the key size.
Tweakable cipher modes such as XTS or LRW SHALL use the 64-byte option
For MediaEncryption mode, the content of the Key column MAY be vendor-specific.
This column defines the encryption mode with which this object SHALL be used. Valid modes are
defined in 5.1.3.73.  MediaEncryption mode permits a vendor-specific encryption mode.
