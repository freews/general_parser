##### 5.3.2.2 General Metadata Group - SPTemplates (Object Table)

> **Section ID**: 5.3.2.2 | **Page**: 155-156

There SHALL be one row in this table for each template used to create the SP, including a row for the
Base Template (for all SPs), and one for the Admin Template in the Admin SP’s SPTemplates table.
