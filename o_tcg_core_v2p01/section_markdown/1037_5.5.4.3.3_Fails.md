##### 5.5.4.3.3 Fails

> **Section ID**: 5.5.4.3.3 | **Page**: 241-241

The SetClockHigh method returns an empty list.  Success or failure of the method invocation is
determinable based on the status code returned in response to the method invocation.
a. If ClockTimeTableUID is not the uid of the ClockTime table.
b. If the SetLagHigh method is not received immediately after the SetClockHigh method.
c. If the value of TrustMode is not Low.
