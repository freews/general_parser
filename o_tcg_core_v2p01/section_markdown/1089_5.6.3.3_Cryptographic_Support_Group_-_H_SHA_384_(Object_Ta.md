#### 5.6.3.3 Cryptographic Support Group - H_SHA_384 (Object Table)

> **Section ID**: 5.6.3.3 | **Page**: 250-250

This section describes the support table for use with SHA-384 hashing operations.  Objects in this table
are used with the HashInit, Hash, HashFinalize, HMACInit, HMAC, HMACFinalize, Sign, and Verify
methods.
