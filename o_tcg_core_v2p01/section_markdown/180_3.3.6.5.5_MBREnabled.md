### 3.3.6.5.5 MBREnabled

> **Section ID**: 3.3.6.5.5 | **Page**: 71-71

MBREnabled SHALL be set to one if LockingEnabled is set to one, and the MBRControl and MBR
tables are implemented, and that the MBRControl table’s Enable column has a value of "True";
otherwise MBREnabled SHALL be set to zero.
