#### 5.6.3.4 Cryptographic Support Group - H_SHA_512 (Object Table)

> **Section ID**: 5.6.3.4 | **Page**: 251-251

This section describes the support table for use with SHA-512 hashing operations.  Objects in this table
are used with the HashInit, Hash, HashFinalize, HMACInit, HMAC, HMACFinalize, Sign, and Verify
methods.
