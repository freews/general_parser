##### 5.1.3.31 feedback_size

> **Section ID**: 5.1.3.31 | **Page**: 108-109

This uinteger type represents the feedback sizes for AES used in CFB mode.  If AES Mode is CFB, this
SHALL be between 1 and the block length.
