##### 5.5.3.1.3 HighByWhom

> **Section ID**: 5.5.3.1.3 | **Page**: 238-238

This is the uidref to the Authority that is in the control authority in the session in which the High Trust
time was set.  This value is valid only if HaveHigh is set to True; otherwise it should be zeroes.
This column SHALL NOT be modifiable by the host.
