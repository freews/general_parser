###### 5.3.2.22.15 Values for C_EC_521

> **Section ID**: 5.3.2.22.15 | **Page**: 188-188

Table 198 represents the set of elliptic curve domain parameters is the fixed set known as P-521 in [11]
and secp521r1 in [19].  The entries p, r, b, x and y represented in that table are example values for a
curve that MAY be used with the C_EC_521 table.  These values are set as the default values for the
associated columns when a new row is created in the C_EC_521 table and when values for those
columns are not specified at table creation. These default values are not represented by a Type table
entry; the TPer SHALL be required to keep track of these values and set them as defaults for new
objects, as necessary.
