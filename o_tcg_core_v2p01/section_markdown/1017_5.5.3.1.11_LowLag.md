##### 5.5.3.1.11 LowLag

> **Section ID**: 5.5.3.1.11 | **Page**: 239-239

The value of this column is set by the SetClockLow method.  This value is valid only if HaveLow is set to
True; otherwise it SHOULD be zeroes.  This represents seconds and fractions of a second.
This column SHALL NOT be modifiable by the host.
