###### 5.3.3.7.1.2 Row

> **Section ID**: 5.3.3.7.1.2 | **Page**: 202-202

For Table.Set on byte tables, "Where = { Row }" identifies the byte address (i.e. RowNumber) where
the Set method is to begin operating.
If the Where parameter is omitted, the Set method's operation begins at the first row of the byte table.
