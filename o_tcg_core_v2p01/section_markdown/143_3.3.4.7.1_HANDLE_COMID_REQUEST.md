#### 3.3.4.7.1 HANDLE_COMID_REQUEST

> **Section ID**: 3.3.4.7.1 | **Page**: 62-62

This command is used to inquire about or manage the state of the ComID previously allocated by the
TPer. The command block for the HANDLE_COMID_REQUEST command is defined in Table 29.
The payload sent by the host to the TPer, at the minimum, consists of the 4-byte Extended ComID and
a Request code. Additional fields MAY be required for some request codes. Currently two request
codes are defined:  VERIFY COMID VALID and STACK RESET.
