##### 5.6.4.5.2 Fails

> **Section ID**: 5.6.4.5.2 | **Page**: 254-254

The result of this method is any remaining decrypted data from the previous Decrypt method
invocation that has not yet been returned to the host.
a. If the object does not exist
b. If the object does not contain a valid credential
c. If there is no decryption “stream” open for this credential object
