##### 5.3.3.3 Basic Table Method Group - Delete (Object Method)

> **Section ID**: 5.3.3.3 | **Page**: 199-199

Successful invocation of this method deletes the object upon which this method was invoked.  See
5.3.4.2.4 for information on deleting table rows and 5.3.4.2.5 for information on deleting tables.
If invoked on an SP object (a row in the Admin SP’s SP table), the SP is deleted (see 5.4.4.2).
