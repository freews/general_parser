###### 5.3.3.10.1.1 FreeRows

> **Section ID**: 5.3.3.10.1.1 | **Page**: 204-204

The result of this method is the number of rows that MAY be additionally created for that table.
The number of rows returned for a table(s) is not directly related to the free space remaining on the SP.
The number of rows is only indicative of how many rows the system is able to generate per table.
