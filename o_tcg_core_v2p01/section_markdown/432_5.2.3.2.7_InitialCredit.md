##### 5.2.3.2.7 InitialCredit

> **Section ID**: 5.2.3.2.7 | **Page**: 151-151

The InitialCredit parameter enables the TPer to provide an amount of credits to the host for use in data
exchange once the session has been successfully opened.  For more information on the buffer
management/flow control mechanism, see 3.3.8.2.
