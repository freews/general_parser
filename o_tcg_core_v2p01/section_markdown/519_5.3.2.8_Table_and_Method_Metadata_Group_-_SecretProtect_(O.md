##### 5.3.2.8 Table and Method Metadata Group - SecretProtect (Object Table)

> **Section ID**: 5.3.2.8 | **Page**: 164-164

This table column is used by the host to identify the key protection mechanism(s), if any, in use by the
storage device to "hide" the device's media encryption key material/secrets.
