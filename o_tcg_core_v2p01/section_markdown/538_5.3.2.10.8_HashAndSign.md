###### 5.3.2.10.8 HashAndSign

> **Section ID**: 5.3.2.10.8 | **Page**: 168-168

The value of the HashAndSign column determines if hashing and signing of session startup method
parameters are required.  If the value of this column is other than “None”, a signed hash of the session
startup method parameters SHALL be used during session startup.
The value of the Operation column and the type of the credential referenced in the Credential
column (and the hash protocol identified in that credential) determine the type of the hashing and
signing.
HashAndSign is only enforced for a particular authority during session startup.  Otherwise, this attribute
SHALL be ignored (for instance, during an Authenticate method invocation).  For additional
information see 5.3.4.1.4.
