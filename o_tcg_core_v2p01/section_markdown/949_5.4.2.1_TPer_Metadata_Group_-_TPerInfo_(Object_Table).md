##### 5.4.2.1 TPer Metadata Group - TPerInfo (Object Table)

> **Section ID**: 5.4.2.1 | **Page**: 229-229

The table in this section describes the metadata that the Admin SP stores about the TPer.  The
TPerInfo table SHALL contain exactly one row that is always readable by the Anybody authority.
