###### 5.2.2.1.2.2 HostProperties

> **Section ID**: 5.2.2.1.2.2 | **Page**: 140-141

This is a list of property names and values that represent the communications capabilities of the TPer.
If the host includes the HostProperties parameter to the Properties method invocation, then this
portion of the method result SHALL include the communications limitations and capabilities that the
TPer SHALL use for messages sent from the TPer to the Host.
