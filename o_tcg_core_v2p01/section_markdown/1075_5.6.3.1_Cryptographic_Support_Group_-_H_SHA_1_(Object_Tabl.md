#### 5.6.3.1 Cryptographic Support Group - H_SHA_1 (Object Table)

> **Section ID**: 5.6.3.1 | **Page**: 248-248

This section describes the support table for use with SHA-1 hashing operations.  Objects in this table
are used with the HashInit, Hash, HashFinalize, HMACInit, HMAC, HMACFinalize, Sign, and Verify
methods.
