##### 5.6.4.8.2 Fails

> **Section ID**: 5.6.4.8.2 | **Page**: 256-256

The result of this method is any remaining encrypted data from the previous Encrypt method
invocation that has not yet been returned to the host.
a. If the object does not exist
b. If the object does not contain a valid credential
c. If there is no encryption “stream” open for this credential object
