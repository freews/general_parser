### 5.7.2.2.14 ReEncryptRequest

> **Section ID**: 5.7.2.2.14 | **Page**: 275-275

A host application requests a re-encryption operation by invoking the Set method on this column.
Successful invocation of the Get method on this column SHALL return no value.
Only state transitions described in 5.7.3.7.1 SHALL be valid.
