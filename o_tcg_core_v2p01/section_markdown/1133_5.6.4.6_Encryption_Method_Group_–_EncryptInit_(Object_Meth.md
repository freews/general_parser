#### 5.6.4.6 Encryption Method Group – EncryptInit (Object Method)

> **Section ID**: 5.6.4.6 | **Page**: 255-255

This method is used to initiate an encryption “stream” using the credential object that invoked the
method.  Only one encryption “stream” SHALL be able to be open at any one time for any individual
credential object.
