###### 5.3.3.18.3 SigningKey

> **Section ID**: 5.3.3.18.3 | **Page**: 209-209

This is a uidref to the credential to be used to decrypt the encrypted key material in the parameterized
package.  This parameter MAY be omitted, if the key material in the parameterized package is being
sent in plaintext.
This is a uidref to the credential to be used to verify the signed hash in the parameterized package.
This parameter MAY be omitted, if the package contents have not been hashed and signed.
