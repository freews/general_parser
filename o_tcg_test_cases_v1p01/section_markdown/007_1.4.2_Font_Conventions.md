#### 1.4.2 Font Conventions

> **Section ID**: 1.4.2 | **Page**: 16-16

Names of methods and SP tables are in Courier New font (e.g., the Set method, the Locking table). Thi
requirement does not apply to method and table names appearing in headings or captions.
Hexadecimal numbers are in Courier New font.
All other text is in the Arial font.
