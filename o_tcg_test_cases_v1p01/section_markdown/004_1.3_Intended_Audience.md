### 1.3 Intended Audience

> **Section ID**: 1.3 | **Page**: 16-16

The intended audience for this document is SD manufacturers and software developers that may wish to tie SDs into
trusted platforms, as well as manufacturers and developers of other components that intend to bind to trusted SDs.
This document is also intended as a reference for test suite vendors.
