#### Table 1: Table_6_9_Device_Limits

| Requirement ID | Description |
| :--- | :--- |
| DEVLMT-1 | The device shall not have any architectural restrictions on the number of times any of the following events can occur: <br> • Firmware downloads and activation supported (see FWUP-2 (number of firmware downloads)); or <br> • Changing password when taking/changing ownership via TCG; or <br> • Crypto erase or block erase (format); or <br> • Power cycles; or <br> • Set/get features (including power state changes); or <br> • Log page or debug log retrievals. |
| | This is not meant to be a test until fail requirement. |
